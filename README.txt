ABENI BOOKS — WEBSITE

This version recreates the blue-and-white look and the key elements from your reference image as a real responsive website: logo, navigation, search, welcome headline, browse/about buttons, featured book mockup, author signature, four feature items, book library, author section and footer.

To add your real books for all visitors:
1. Put each PDF in the books/ folder.
2. Edit the `books` array near the start of the script in index.html and add an entry. Set `pdf` to the correct path, e.g. `books/my-book.pdf`.
3. Optional: add a cover image in assets/ and set `cover` to its path.
4. Upload the whole folder to GitHub Pages, Netlify or Vercel.

The “Add a book” button is a local browser preview only; it does not publish a file to all visitors. Public admin uploads need backend storage and authentication. Replace the contact placeholder before publishing.
